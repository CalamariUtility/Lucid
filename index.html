Introducing Lucid

Running a script should be the easy part. You shouldn’t have to trade performance for compatibility, lose your setup when you change games, or guess what went wrong.

Lucid brings it all into one macOS workspace. A complete, optimized script environment, an editor with useful diagnostics, and a home for every game, script and client. Built to work together from the start.

The first Lucid macOS IDE utility to beat Opiumware, MacSploit, Helios and Hydrogen.

Any script that exists, Lucid can run it for you, flawlessly.

Built by the community’s top developers. Lucid’s environment combines optimized execution, complete libraries and precise error reporting. Scripts load quickly, their libraries behave as expected, and errors point to the script that failed.
